# نگارخانه مهر — نسخه ۰.۴

## چیدمان
این نسخه یک تالار ورودی و چهار تالار پیوسته دارد:
1. نقاشی
2. عکاسی
3. هنرهای دستی
4. هنرهای آوایی

دیوارهای جداکننده و دیوارهای پیرامونی به‌صورت پیوسته و متصل ساخته شده‌اند؛ فقط چهار درگاه مشخص، تالار ورودی را به اتاق‌ها وصل می‌کنند. کف کاشی‌کاری‌شده نیز یک سطح پیوسته است.

## بخش هنرهای دستی
شش نمونه سه‌بعدی روی شش میز نمایش قرار گرفته‌اند: گلدان سفالی، کاسه لعاب‌دار، جعبه چوبی، سبد بافتنی، کاشی تزئینی و پرنده چوبی. با کلیک روی هر نمونه، توضیحات آن باز می‌شود.

## بخش هنرهای آوایی
شش سازه آوایی سه‌بعدی روی پایه‌های نمایش نصب شده‌اند. با کلیک روی هر سازه، قطعه کوتاه موسیقی اختصاصی آن پخش می‌شود. صدا به‌صورت موسیقی الکترونیکی/آوایی ساخته‌شده با Web Audio API تولید می‌شود و فایل آهنگ دارای حق نشر از بیرون بارگیری نمی‌شود. داخل پنجره اثر دکمه پخش مجدد و توقف نیز وجود دارد.

## توسعه‌پذیری
تعریف اتاق‌ها در ابتدای `app.js` و در آرایه `SECTIONS` قرار دارد. هر بخش دارای `id`، `name`، `type` و `items` است.
- برای افزودن نقاشی یا عکاسی، یک بخش با نوع `painting` یا `photography` تعریف کنید.
- برای بخش اشیای سه‌بعدی روی میز، نوع `crafts` استفاده می‌شود.
- برای بخش موسیقی تعاملی، نوع `audio` استفاده می‌شود.
- عرض ساختمان و مرکز اتاق‌ها از تعداد عناصر `SECTIONS` محاسبه می‌شود و با افزودن بخش جدید، نقشه به‌صورت خودکار عریض‌تر می‌شود.

برای ساخت نوع نمایش کاملاً جدید، باید یک تابع رندر جدید به بخش ساخت اتاق‌ها اضافه شود؛ اما برای افزودن اتاقی از انواع فعلی نیازی به بازنویسی پروژه نیست.

## کنترل‌ها
- رایانه: W A S D یا کلیدهای جهت‌نما برای حرکت.
- چرخش دید: کلیک چپ را نگه دارید و ماوس را بکشید. نشانگر مخفی نمی‌شود و Pointer Lock استفاده نشده است.
- اندروید: جوی‌استیک پایین سمت چپ برای حرکت و کشیدن انگشت روی فضای نمایش برای چرخش دید.
- کلیک روی تابلو، شیء دستی یا سازه آوایی، اطلاعات آن را نمایش می‌دهد.

## اجرا و انتشار
برای اجرای محلی، پوشه را در VS Code باز کنید و با افزونه Live Server فایل `index.html` را اجرا کنید.
برای انتشار روی GitHub Pages، محتویات پوشه را در ریشه مخزن قرار دهید و از Settings → Pages شاخه `main` و پوشه `/ (root)` را انتخاب کنید.

## نکات
- آثار و نام‌ها نمونه‌اند؛ آثار واقعی دانش‌آموزان هنوز جایگزین نشده‌اند.
- صداها قطعه‌های کوتاه و اصلیِ سنتزشده در مرورگر هستند، نه ضبط اجرای ساز واقعی.
- Babylon.js و فونت Vazirmatn از CDN دریافت می‌شوند؛ برای اجرا اتصال اینترنت لازم است.
- کد JavaScript بررسی نحوی می‌شود، اما همچنان باید در مرورگر و گوشی واقعی آزمایش شود.
